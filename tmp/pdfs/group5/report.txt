           1.  Software Codebase                                                    
               Software Codebase: TVPSSHub                                          
                                                                                    
               TVPSSHub is a web-based school management system developed to support the management of
               TV Pusat Sumber Sekolah (TVPSS) activities, including programmes, schools, users, feedback,
                                                                                    
               and resource requests. The system provides role-based access for administrators, teachers, and
               students, allowing each user to perform tasks according to their responsibilities. It was developed
                                                                                    
               using Java with the Spring Boot framework, Spring MVC, Thymeleaf, Hibernate, Spring
               Security, and MySQL, following the Model-View-Controller (MVC) architecture. The project
               contains well over 500 lines of code (excluding comments and blank lines) and serves as the
                                                                                    
               codebase for analysing code smells and applying refactoring techniques in this report.
